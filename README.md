# سالن زیبایی رویای زیبا - Beauty Salon Booking System

یک سیستم رزرو آنلاین وقت برای سالن‌های زیبایی با استفاده از Next.js 16 و MongoDB.

## ویژگی‌ها

- 🎨 طراحی زیبا و مدرن با Tailwind CSS
- 📱 ریسپانسیو و سازگار با موبایل
- 💇‍♀️ ۵ سرویس مختلف: کوتاهی مو، رنگ مو، مژه، ناخن کاری، عروس
- 📅 سیستم رزرو آنلاین وقت
- 📱 ارسال پیامک تایید با sms.ir
- 👨‍💼 پنل مدیریت برای مشاهده و مدیریت وقت‌ها
- 🔍 فیلتر و جستجوی پیشرفته

## تکنولوژی‌ها

- **فریم‌ورک**: Next.js 16 (App Router)
- **دیتابیس**: MongoDB با Mongoose
- **استایل**: Tailwind CSS
- **زبان**: TypeScript
- **SMS**: sms.ir API

## راه‌اندازی

### پیش‌نیازها

- Node.js 18+
- MongoDB (محل یا MongoDB Atlas)
- API Key از sms.ir

### نصب

```bash
# نصب وابستگی‌ها
npm install

# تنظیم متغیرهای محیطی
cp .env.example .env
```

### تنظیم متغیرهای محیطی

```env
# MongoDB connection string
MONGODB_URI=mongodb://localhost:27017/beauty_salon

# SMS.ir API Key
SMS_API_KEY=your_sms_ir_api_key_here
```

### اجرای پروژه

```bash
# توسعه
npm run dev

# تولید
npm run build
npm start
```

## استفاده از پنل مدیریت

برای دسترسی به پنل مدیریت:
1. به آدرس `/admin` بروید
2. می‌توانید وقت‌ها را مشاهده، فیلتر و جستجو کنید
3. وضعیت وقت‌ها را تغییر دهید (تایید، لغو، تکمیل)
4. وقت‌ها را حذف کنید

## تنظیم SMS.ir

1. در سایت [sms.ir](https://sms.ir) ثبت‌نام کنید
2. از پنل کاربری API Key دریافت کنید
3. در فایل `.env` مقدار `SMS_API_KEY` را تنظیم کنید
